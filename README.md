# The 1000cr D2C Operating Map

Every function a lean, AI-native team must cover to build a 1000cr brand with 5-10 people.

**12 functions. 96 tasks. 58 that AI can own.**

## What's inside

- `index.html` - The interactive operating map (click any function to see tasks + AI playbook)
- `index_codex.html` - Original codex version
- `linkedin-capture.html` - LinkedIn image capture template (1200x1200)
- `1000cr-operations-map.png` - LinkedIn post image

## The 5 layers

1. **Build the product** - Market research, product development, supply chain
2. **Get customers** - Brand marketing, performance marketing, creator/influencer
3. **Sell everywhere** - Distribution channels, app and web platform
4. **Keep customers** - Customer experience, data and analytics
5. **Run the company** - Finance and legal, AI and knowledge OS

**Layer 0: Agent OS** - RAG, memory, automation, orchestration that ties it all together.
